# Contributing

This is currently a single-maintainer public demo repository.

## Development

```bash
pnpm install --frozen-lockfile
pnpm lint
pnpm typecheck
pnpm test
pnpm build
```

The standard local gate is:

```bash
pnpm verify
```

For browser smoke checks, run:

```bash
pnpm verify:e2e
```

## Pull requests

Target `dev`; agents never merge PRs or deploy. Use signed Conventional Commits.
Describe acceptance criteria and attach verification results. For workflow changes,
include rejected roles/actions and the relevant transition or deadline fixture.

## Setup and source boundaries

Use Node 22 and pnpm 10.15.1: `pnpm install --frozen-lockfile`.
No credentials or private tools are required for local checks. Install Chromium
with `pnpm exec playwright install chromium` before `pnpm verify:e2e`.
Use `wt new chore/my-change origin/dev` under this repo's `.worktrees/`, or use a
separate clone and a topic branch from origin/dev if wt is unavailable.

`src/law544/transitions.ts` owns allowed state/role transitions; do not encode
parallel permissions in UI components. Keep required document hashes and terminal
states enforced by `assertAllowedTransition`. Deadline rules are demo behavior,
not legal advice. `src/ledger/` and `src/shared/crypto.ts` own tamper evidence;
`src/api/transitionIngestion.ts` owns ingestion validation and replay rejection.
Preserve encrypted document storage and fictional, privacy-safe fixtures.
Never add real citizen records, production keys, or live administration data.
`public/build-info.json` and dist/ are generated by the build; do not edit them.

The CI `verify` job requires both existing unit/privacy/build checks and Playwright.
Production publishing is separate and maintainer-operated.
