# Security Policy

## Supported versions

The `main` branch is supported.

## Reporting a vulnerability

Please report security issues privately through GitHub private vulnerability reporting once enabled for the repository.

Do not include real personal data, Romanian national identifiers, access tokens, private keys, or production credentials in issues, pull requests, fixtures, or demo exports.

## Demo privacy model

This project is a browser-only civic technology demo. It stores demo state locally in the browser using localStorage and IndexedDB. It must not be used for real Law 544/2001 submissions or real citizen documents.
